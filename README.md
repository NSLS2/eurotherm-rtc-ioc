# eurotherm_rtc

EPICS IOC support for a Eurotherm RTC temperature controller. The IOC communicates with the controller over Modbus/TCP and provides process variables for system status, device configuration, setpoints, alarms, and control parameters for the EPC3016 controller.

The repository contains the IOC startup configuration, Eurotherm Modbus register map, EPICS database records, and support files for integrating the controller into EPICS.
